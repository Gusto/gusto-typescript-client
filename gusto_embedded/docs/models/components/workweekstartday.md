# WorkweekStartDay

The day of the week that this pay schedule's workweeks start on, used for regular rate of pay overtime calculations.


## Example Usage

```typescript
import { WorkweekStartDay } from "@gusto/embedded-api/models/components/payschedulecreaterequest.js";

let value: WorkweekStartDay = "Monday";
```

## Values

```typescript
"Sunday" | "Monday" | "Tuesday" | "Wednesday" | "Thursday" | "Friday" | "Saturday"
```
