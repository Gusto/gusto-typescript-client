# Category

The earning type category. Only settable when the company has access to categorized custom bonus earning types.

## Example Usage

```typescript
import { Category } from "@gusto/embedded-api/models/operations/postv1companiescompanyidearningtypes.js";

let value: Category = "Other";
```
