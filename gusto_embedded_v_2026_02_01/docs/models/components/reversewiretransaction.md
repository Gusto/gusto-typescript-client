# ReverseWireTransaction

Representation of a reverse wire (drawdown) transaction. Reverse wires are debit transactions initiated by Gusto to pull funds from a partner's bank account to cover payroll or contractor payment obligations.

## Example Usage

```typescript
import { ReverseWireTransaction } from "@gusto/embedded-api-v-2026-02-01/models/components/reversewiretransaction.js";

let value: ReverseWireTransaction = {
  companyUuid: "<id>",
  amount: "<value>",
  status: "failed",
  paymentDirection: "debit",
  createdAt: "1734214176015",
};
```
